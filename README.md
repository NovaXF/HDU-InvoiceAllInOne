# HDU 发票工作台

一个用于整理发票报销材料的 Windows 小工具。主要为了节省给文件重新命名、填写报销 Excel 的时间，并通过加载已有工作区，辅助避免已报销过的发票再次提交。

## 主要功能

- 读取发票 PDF，按规则整理、重命名文件，按张数和金额上限分叠。
- 自动生成包含项目名称、发票号码、金额和实际报销人的 Excel 清单，减少重复填写。
- 打开已有叠后，按发票号码对比新导入的发票；改过文件名也能查重。**查重范围仅限当前已加载的工作区记录，程序不会自动得知其他渠道的报销情况。**
- 保留订单截图识别与匹配，以及撤销、重做和主题切换。

## 使用

从 [GitHub Release](https://github.com/NovaXF/HDU-InvoiceAllInOne/releases/latest) 下载 `Portable.exe`，双击即可运行。Windows 64 位免安装版已包含所需运行环境，启动展开依赖时需要稍候片刻。

1. 选择输出目录，填写预约人和实际报销人。
2. 有历史报销记录时，先点击“打开已有叠”，加载对应工作区。
3. 拖入发票 PDF，等待识别，再点击“一键分叠”或手动调整。
4. 核对发票和清单信息，点击“保存并输出”，并保留工作区状态文件，方便下次加载查重。

完整操作见程序内“使用说明”。

## 关于订单截图

订单截图功能主要用于适配旧报销规则，方便识别金额、快速匹配发票。新规下的主要流程不再依赖这部分功能，因此之后没有继续针对新规优化，目前仍保留供需要时使用。

按当前使用场景的报销要求，单张发票金额超过 **1000 元** 时，仍需附订单截图和支付记录，因此暂未移除截图功能。非必要时，尽量避免开具单张金额超过 1000 元的发票；确需报销时，请自行准备完整材料。具体要求以学校或所在单位的最新通知为准。

## 本地数据与更新

发票和截图在本地识别，不会随更新检查上传。设置默认保存在 `%LOCALAPPDATA%\HDU-InvoiceAllInOne`，可在设置的“本地数据位置”打开或更改；报销输出目录单独管理。

启动后会在后台检查版本，也可手动“检查更新”或点击“前往下载”。更新时先保存工作区、关闭旧程序，再手动替换 exe，已有本地设置会继续保留。
